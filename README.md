# Python-MNE-Tutorial

Setup for [MNE-Python](https://mne.tools/).

---

### 1. Create a python Environment

Using standard Python `venv`:

```bash
# Create environment
python -m venv mne-env

# Activate on macOS/Linux
source mne-env/bin/activate

# Activate on Windows
mne-env\Scripts\activate
```
### 2. Install packages
```bash
pip install --upgrade pip

# Install Jupyter Notebook / Lab
pip install notebook

# Install MNE-Python
pip install mne

# Install the neuro-pipeline
pip install hu-neuro-pipeline
```
